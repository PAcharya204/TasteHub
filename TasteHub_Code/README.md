# TasteHub – Android Food Ordering Application

TasteHub is an Android food ordering application built with Java, XML, Android Studio, and SQLite.

## Features
- User registration and login
- Browse and search food items
- View food details and manage cart quantities
- Delivery address management
- Checkout and payment-method selection
- Order confirmation and order history
- Profile management and clear-history option

> Feature availability may depend on the current implementation.

## Tech Stack
- Java
- XML layouts
- SQLite (`SQLiteOpenHelper`)
- Android Studio / Android SDK
- Gradle Kotlin DSL (`.gradle.kts`)

## Open the project
1. Install Android Studio.
2. Download or clone this repository.
3. Open the folder containing `settings.gradle.kts` in Android Studio.
4. Install the Android SDK platform/build tools requested by Android Studio.
5. Allow Gradle sync to finish, then run the `app` configuration on an emulator or Android device.

The Android SDK, emulator images, local `local.properties`, Gradle caches, and generated build outputs are intentionally not included. Android Studio/Gradle can recreate generated files on your computer.
