# TasteHub – Android Food Ordering Application 

TasteHub is an Android food ordering application developed using Java, XML, and SQLite. It provides a simple and user-friendly interface for browsing food items, managing a cart, and placing orders.

## ✨ Features

* **User Authentication:** User registration and login.
* **Home Page:** Browse food items and categories.
* **Search:** Find food items by name or category.
* **Food Details:** View food information and prices.
* **Shopping Cart:** Add food items and manage quantities.
* **Checkout:** Manage delivery addresses and select a payment method.
* **Order Management:** View order confirmations and order history.
* **Profile Management:** Manage profile information and clear order history.

## 🛠️ Technologies Used

* **Language:** Java
* **UI Design:** XML
* **Database:** SQLite
* **Database Management:** SQLiteOpenHelper
* **Development Environment:** Android Studio
* **Build System:** Gradle

## 🚀 How to Run the Project

1. Install [Android Studio](https://developer.android.com/studio).
2. Clone or download this repository.
3. Open the Android project folder containing `settings.gradle.kts` in Android Studio.
4. Install the Android SDK components requested by Android Studio.
5. Allow Gradle synchronization to complete.
6. Run the application on an Android emulator or a connected Android device.
